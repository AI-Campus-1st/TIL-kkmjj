숫자 타입
(1) int (정수)
모든 정수는 int로 표현
8진수: 0o / 2진수 0b / 16진수 0x

(2) float (부동소수점 , 실수)
항상 같은 값으로 일치되지 않음
Ex) 3.5 - 3.12 => 0.379999~ 로 나옴
	3.5-3.12 == 0.38 => false

(3) complex(복소수)
각각 실수로 표현되는 실수부와 허수부를 가짐
복소수는 허수부를 j로 표현

논리연산자
A and b -> a와b 모두 True일 때만 True
A or b -> a와 b 모두 False일 때만 False
Not a -> True => False / False => True

*and -> a가 거짓이면 a를 리턴/ 참이면 b를 리턴
Ex) 3 and 5 -> 5(b의 값인 5를 리턴)
*or -> a가 참이면 a를 리턴 / 거짓이면 b를 리턴
Ex) 0 and 3 -> 3(0은 False로 취급하기 때문)
