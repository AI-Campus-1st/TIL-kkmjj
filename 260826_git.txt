Pool | map
- 함수 하나와 인자 목록만 있으면 됨
* Pool.map(f, args) -> 함수를 인자 목록에 하나씩 적용
* 결과는 인자 순서 그대로 리스트로 돌아옴
* with문을 쓰면 풀이 자동으로 정리

multiprocessing.dummy
- 스레드 
* multiprocessing.dummy 는 프로세스 API를 그대로 흉내낸 스레드 구현
EX)

# 아래 코드는 한 글자도 바뀌지 X

Map 계열 4가지
메서드	인자	결과	쓰는 때
map	인자 하나	순서대로 리스트	기본값
starmap	인자 여러 개(튜플)	순서대로 리스트	함수가 인자를 둘 이상 받을 때
imap	인자 하나	순서대로 이터레이터	결과가 크거나 진행률을 보고 싶을 때
imap_unordered	인자 하나	끝난 순서대로	순서가 상관없고 가장 빠를 때
인자가 여러개 일 때 
- starmap가 튜플을 풀어서 넘겨줌

args = [(URL, p) for p in range (1, 11)]

(2) 비동기
- 스레드를 늘리는 대신, 기다리는 동안 다른 일을 함 
* 스레드는 OS가 번갈아 실행 시켜줌
* 비동기는 하나의 스레드 안에서 기다림이 생길 때마다 다음 작업으로 넘어감
* Async / await 문법으로 코드 다시 써야함

Https - requests
- 동기 코드는 requests와 거의 같음
* 같은 라이브러리가 비동기도 지원

AsyncClient / gather
- 비동기 수집 기본
* await가 붙은 지점에서 다른 작업으로 넘어감
* return_exceptions=True -> 하나가 실패해도 전체가 멈추지 않음
* 결과가 예외 객체에 섞여 오므로 뒤에서 걸러내야함

동시 수 제한
- 비동기는 제한을 걸지 않으면 위험함
EX)
async def fetch(client, url, sem):
	async with sem: # 동시에3개까지만
		r = await client.get(url)
		await asyncio.sleep(0.7) # 매너지연
		return r.text
async def main(urls):
	limits = httpx.Limits(max_connections=3)
	sem = asyncio.Semaphore(3)
	async with httpx.AsyncClient(limits=limits, timeout=10) as client:
		tasks = [fetch(client, u, sem) for u in urls]
		return await asyncio.gather(*tasks, return_exceptions=True
* asyncio.Semaphore 동시에 진행되는 작업 수 묶음
* httpx.Limits 커넥션 수도 제한
