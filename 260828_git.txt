파이프 라인

1. 데이터 파이프라인 전체 흐름

수집 → Raw → Clean → Mart → 검증

수집 : 웹/API에서 데이터 가져오기
Raw   : 가져온 원본 그대로 저장
Clean : 원본 데이터를 사용하기 좋게 정제
Mart  : 분석에 필요한 형태로 집계/계산
검증  : 만들어진 데이터에 문제가 없는지 확인

핵심 구조
 Raw → Clean → Mart 

2. Raw
- 수집한 데이터를 수정하지 않고 그대로 저장하는 곳

EX)
날짜     : "20260828"
종목코드 : "005930"
종가     : "54,400"
거래량   : "11,559,385"

문자열이나 쉼표 등이 있어도 Raw에서는 수정X

Raw를 저장하는 이유
- 데이터 수집은 오래 걸리지만 이미 수집한 데이터를 다시 파싱하거나 정제하는 것은 빠름.

Raw가 없는 경우
정제 코드 오류
→ 데이터 다시 수집
→ 다시 정제

Raw가 있는 경우
정제 코드 오류
→ Raw 다시 불러오기
→ 정제만 다시 수행

수집 = 비쌈
파싱/정제 = 쌈

원칙
- Raw는 절대 수정하지 않는다.
- Clean이나 Mart에 문제가 생기면 Raw를 이용해서 다시 만든다.


3. Clean
- Raw 데이터를 일관된 형식으로 정리한 데이터이다.

EX)
[Raw]
날짜   = "2026.08.28"
종가   = "54,400원"
종목명 = " 삼성전자 "
↓
[Clean]
날짜   = 2026-08-28
종가   = 54400
종목명 = 삼성전자

Raw
 ↓
결측 처리
중복 처리
날짜 형식 통일
숫자 변환
문자열 정리
 ↓
Clean

4. 데이터 품질 문제 6가지
1) 결측
2) 중복
3) 포맷 불일치
4) 타입 오염
5) 인코딩
6) 잔여물

5. 결측
- 값이 없는 경우
EX)
삼성전자     70000
SK하이닉스   NULL
현대차       220000

결측 개수 확인
- df.isna().sum()

결측률 확인
- df.isna().mean()

처리 방법
1) 삭제
df.dropna()
2) 특정 값으로 채우기
df.fillna(...)
3) 그대로 유지

주의
NULL ≠ 0
값이 없다는 것과 실제 값이 0이라는 것은 의미가 다름
따라서 무조건 0으로 바꾸면 안됨.

6. 중복
- 중복이란 같은 데이터가 여러 번 들어온 경우이다.

EX)
2026-08-28 | 005930 | 70000
2026-08-28 | 005930 | 70000

중복 제거 예시
df.drop_duplicates(
    subset=["obs_dt", "stn_id"],
    keep="last"
)

subset
→ 어떤 컬럼을 기준으로 같은 데이터인지 판단할 것인지 지정

keep="last"
→ 중복 데이터 중 마지막 데이터를 남김
* 중복을 삭제하기 전에 어떤 데이터가 중복인지 먼저 확인하는 것이 중요


7. 날짜 포맷 통일
- 출처마다 날짜 형식이 다를 수 있음

EX)

변환 후에는 실패한 값이 몇 개인지 확인해야 함.

df["날짜"].isna().sum()

* 단위나 쉼표 등이 섞여 있으면 먼저 제거

def to_num(s):
    return (
        s.astype(str)
        .str.replace(r"[^\d.\-]", "", regex=True)
        .replace("", pd.NA)
        .pipe(pd.to_numeric, errors="coerce")
    )

* 빈 문자열은 0이 아니라 NaN으로 처리

16. Mart
- 분석 질문에 바로 답할 수 있도록 Clean 데이터를 집계하거나 계산한 데이터

Clean = 정리된 원자료
Mart = 질문의 답

EX)
[Clean]
날짜    종목       종가
8/26   삼성전자    70000
8/27   삼성전자    71000
8/28   삼성전자    72000
↓
[Mart]
종목       월       평균종가
삼성전자   2026-08  71000
* 매번 계산하지 않고 자주 사용하는 분석 결과를 미리 만들어 두는 것


17. groupby + agg
- Mart를 만들 때 자주 사용

groupby
→ 어떤 기준으로 묶을 것인가

agg
→ 묶은 데이터로 무엇을 계산할 것인가

EX)
monthly = (
    clean
    .groupby(
        ["stn_id", "stn_nm", "ym"],
        as_index=False
    )
    .agg(
        avg_ta=("avg_ta", "mean"),
        max_ta=("avg_ta", "max"),
        sum_rn=("sum_rn", "sum"),
        days=("obs_dt", "count")
    )
)

EX) 주식 데이터
삼성전자 데이터끼리 묶기
        ↓
평균 종가 계산
최고 종가 계산
거래일 수 계산

19. 이동평균

3일 이동평균 예시

1일 = 10
2일 = 20
3일 = 30

3일 이동평균
= (10 + 20 + 30) / 3
= 20

다음 날 값이 40이라면

2일 = 20
3일 = 30
4일 = 40

4일 이동평균
= (20 + 30 + 40) / 3
= 30

Python 예시

df["ma7"] = (
    df.groupby("stn_id")["avg_ta"]
      .transform(
          lambda s: s.rolling(7).mean()
      )
)

이동평균을 계산할 때는

1) 그룹을 나눈다.
2) 날짜순으로 정렬한다.
3) rolling()을 사용한다.
* 순서가 중요

20. 데이터 검증

주요 검증 항목
1) 총 건수
2) 기간
3) 결측률
4) 중복률
5) 변환 실패
6) 이상치

21. 총 건수

df["날짜"].max()

24. 중복률

28. 멱등성
- 같은 작업을 여러 번 실행해도 최종 결과가 동일한 성질

* 잘못된 경우
1번 실행 → 100건
2번 실행 → 200건
3번 실행 → 300건
- 실행할 때마다 같은 데이터가 계속 추가
- 
* 멱등성이 있는 경우
1번 실행 → 100건
2번 실행 → 100건
3번 실행 → 100건
- 몇 번 실행해도 결과가 같음

29. 멱등성을 만드는 방법

EX)
def run():

    load_raw()
    # Raw 증분 적재
    # UPSERT로 중복 방지

    build_clean()
    # Clean 전체 재생성

    build_mart()
    # Mart 전체 재생성

    report()
    # 검증

구조

Raw
→ UPSERT로 중복 방지
Clean
→ 전체 재생성
Mart
→ 전체 재생성
- 프로그램을 여러 번 실행해도 결과가 같도록 만듬

30. UPSERT
- 데이터가 없으면 → INSERT
- 데이터가 이미 있으면 → UPDATE
- 같은 데이터를 다시 수집해도 중복으로 계속 추가되는 것을 막을 수 있음

31. 재실행 정책
Raw
→ 새로 수집된 데이터만 증분 적재
→ UPSERT

Clean
→ 전체 재생성

Mart
→ 전체 재생성
* Clean과 Mart는 삭제해도 Raw를 이용해서 다시 만들 수 있어야 한다.
