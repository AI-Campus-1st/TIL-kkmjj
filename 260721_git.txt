git

gitHub - 커뮤니티(게시판)
git - 글 작성 프로그램(올리는것 까지)


최초 작성자 설정
git config --global user.name "닉네임"
git config --global user.email "GitHub 이메일"

최초 1번
git clone 저장소 주소 (복제)
-> git pull

내가 만든거 올리는 방법
최초 1회
Git init - 여기를 git 저장소 폴더로 관리하겠다.

저장소 연결
Git remote add origin 저장소 주소

저장소에 올리기
Git add 파일들 (모든 파일 => '.') -> git status
Git commit -m "기록 메시지" -> git log
Git push origin master (main)

또 올리기
-> 반복.
