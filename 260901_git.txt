Streamlit 기본 문법

1. Streamlit
- Python으로 데이터 웹 애플리케이션을 쉽게 만들 수 있는 프레임워크
- 데이터 분석 결과를 빠르게 시각화할 수 있음
- 사용자 입력에 따른 상호작용 지원

2. Streamlit 실행 구조
- Python 스크립트 기반
- 코드는 위에서 아래로 순서대로 실행됨
- 사용자가 위젯을 조작하면 스크립트가 다시 실행됨
- 코드 변경 시 UI가 자동으로 업데이트됨

3. Widget
- 사용자에게 값을 입력받거나 상호작용할 때 사용

st.button()
→ 버튼

st.slider()
→ 슬라이더

st.text_input()
→ 텍스트 입력

4. 텍스트 출력

st.text()
→ 일반 텍스트 출력

st.markdown()
→ Markdown 문법을 사용하여 출력
→ HTML/CSS 적용 가능

5. Markdown 문법

제목
# 제목
## 작은 제목

굵은 글씨
**내용**

목록
- 항목1
- 항목2

링크
[표시할 글자](주소)

이미지
![이미지 설명](이미지 주소)


6. 데이터 표현

st.table()
→ 정적인 테이블

st.dataframe()
→ 데이터프레임을 동적으로 표시
→ 스크롤, 정렬 등의 상호작용 가능

st.metric()
→ 주요 수치와 변화량 표시

st.json()
→ JSON 데이터를 계층 구조로 표시

EX)

st.table(df)
st.dataframe(df)
st.metric(
    label='온도',
    value='25°C',
    delta='1.2°C'
)
st.json(data)

7. 데이터 시각화

st.line_chart()
→ 선 그래프

st.bar_chart()
→ 막대 그래프

- Plotly, Matplotlib, Seaborn 등의 시각화 라이브러리와 함께 사용 가능

8. Layout
- 화면의 구조와 배치를 설정

st.sidebar
→ 사이드바

st.columns()
→ 화면을 여러 열로 나눔

st.expander()
→ 내용을 접고 펼칠 수 있게 함

9. st.sidebar

화면 왼쪽에 사이드바 생성

EX)
st.sidebar.title('사이드바')
name = st.sidebar.text_input('이름')

10. st.columns()

화면을 여러 개의 열로 나눌 때 사용
EX)
cols = st.columns(2)
with cols[0]:
    st.write('첫 번째 칼럼')
with cols[1]:
    st.write('두 번째 칼럼')

11. st.expander()

내용을 접었다 펼칠 수 있게 함

EX)
with st.expander('더보기'):
    st.write('내용입니다.')

12. State Management

st.session_state
→ 사용자 입력이나 계산 결과 등의 상태를 저장

- Streamlit은 위젯을 조작할 때마다 코드가 다시 실행되므로
  값을 유지해야 할 때 사용


13. Caching

@st.cache_data
→ 데이터 로딩이나 복잡한 계산 결과를 저장
→ 같은 작업이 반복되는 것을 줄여줌
