[추천시스템]
사용자가 관심을 가질 만한 정보를 추천하는 시스템

[벡터화]
콘텐츠를 일련의 숫자 목록으로 표현하는 것
→ 서로 다른 콘텐츠도 숫자로 표현하여 비교 가능

[차원]
벡터를 구성하는 특징의 개수

[유클리디언 거리]
벡터 사이의 거리로 유사도 판단
→ 거리가 가까울수록 유사

[코사인 유사도]
벡터 사이의 각도로 유사도 판단
→ 같은 방향일수록 유사도가 높음

[추천 기본 흐름]
콘텐츠 벡터화
→ 유사도 계산
→ 유사도 순으로 정렬
→ 추천

[콘텐츠 기반 필터링]
사용자가 좋아한 아이템과
특징이 비슷한 아이템을 추천
→ 콘텐츠 자체의 특징 사용

[협업 필터링]
사용자와 아이템 간의 관계를 분석
→ 사용자의 과거 행동·평가 데이터 사용

[하이브리드 필터링]
여러 추천 방식을 결합
→ 각 방식의 단점을 서로 보완

[Cold Start]
신규 사용자/신규 상품처럼
기존 행동·평가 데이터가 부족하여
추천하기 어려운 문제

백터화 -> 유사도 계산 -> 추천
