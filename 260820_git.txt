Network 구조
1. Name 
- 요청한 파일 이름. 데이터 요청은 확장자가 없거나 jsond인 경우 많음 
2. Status
- 응답코드 200이 아닌 요청은 후보에서 제외
3. Type
- 요청의 종류 (fetch / xhr) -> 찾는 것 
4. 응답 크기
- 데이터를 담은 요청은 대게 큼

Fetch/XHR 필터
- 가장 먼저 눌러야 함
* 자바스크립트가 보낸 데이터 요청만 남김

Preserve log
- 페이지가 넘어가도 기록을 남김
* 체크하지 않으면 페이지 이동 순간 목록 초기화
* Clear 후 시작하면 깔끔

Json - 데이터 표준 형식
* 중괄호는 딕셔너리, 대괄호는 리스트
* 키는 -> “ “ |  ‘ ‘ -> json X
* true/false/null 이파이썬에서는 True/False/Non 

JSON과 파이썬
- 옮겨 담을 때 이름만 바뀜
 
JSON	파이썬	예시
object	dict	{"id": 1}
array	list	[7, 2, 3]
string	str	"orange"
number	int• float	12345
true / false / null	True / False / None	-

Response.json()
- 한 줄이면 딕셔너리
EX)
Data = response.json() # 권장
# 같은 일 
Import json
Data = json.loads(response.text)

->  응답이 json이 아니면 예외
* response.json() 인코딩까지 알아서 처리
* JSON이 아닌 응답에 부르면 JSONDecodeError
* 실패 ->  response.text[:200] 확인

중첩 구조 접근
- 한겹씩 내려감
EX)
data = response.json()
items = data["items"]
for item in items:
print(item[" hname"], item[" aud"])
# 키가 없을 수 있음 -> .get() 써야함
print(item.get("hname", ""))

-> 리스트가 나오면 반복문, 딕셔너리가 나오면 키 접근

리스트 안의 딕셔너리
- 크롤링 결과 가장 흔한 모양
EX)
result = []
for item in items:
	result.append({
		"제목 ": item.get("hname", ""),
		"관객수 ": item.get("aud", ""),
	})

import pandas as pd
pd.DataFrame(result).to_csv("out.csv", index=False,
				encoding="utf - 8- sig")

-> DataFrame, CSV, DB 바로 감
* 키 이름은 수집 시점에서 한글로 통일
