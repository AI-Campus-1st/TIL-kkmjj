1. 텍스트 전처리 (Text Preprocessing)

- 자연어 처리를 위해 텍스트를 분석 목적에 맞게 표준화하는 작업
- 토큰화, 불필요한 조사 및 특수문자 제거, 불용어 제거 등을 포함
- 텍스트의 중요한 정보를 유지하고 분석 효율성을 높임
- Garbage In, Garbage Out: 입력 데이터의 품질이 결과에 영향을 미침


2. 토큰화 (Tokenization)

① 문장 토큰화
- 문장을 기준으로 텍스트를 분리
- 마침표(.), 느낌표(!), 물음표(?) 등을 활용
- 구두점만으로는 정확한 분리가 어려울 수 있음

② 단어 토큰화
- 문장을 단어 단위로 분리
- 영어: 공백을 기준으로 비교적 쉽게 분리
- 한국어: 조사 등을 고려한 형태소 분석 필요

③ 고려사항
- 구두점 및 특수문자를 무조건 제거하면 안 됨
- Don't: 아포스트로피 처리
- State-of-the-art: 하이픈 처리
- New York: 공백을 포함한 하나의 고유명사


3. 토큰 처리 (Token Processing)

① 품사 태깅 (POS Tagging)
- 각 토큰에 명사, 동사, 형용사 등의 품사 정보 부여
- 필요한 품사를 추출하거나 불필요한 품사를 제거할 때 사용

② 개체명 인식 (NER)
- 사람, 조직, 지역, 날짜, 숫자 등의 개체 식별
- 텍스트의 주제를 파악하거나 검색 엔진 색인에 활용

③ 청킹 (Chunking)
- 의미적으로 관련된 토큰을 하나의 덩어리로 묶는 기법


4. 원형 복원

- 토큰의 원형을 복원하여 표준화
- 불필요한 중복을 줄이고 연산 효율성을 높임

① 어간 추출 (Stemming)
- 품사를 무시하고 규칙에 따라 어간 추출
- 실제 단어가 아닌 결과가 나올 수 있음

예시)
running → run
beautiful → beauti
believes → believ
studies → studi

② 표제어 추출 (Lemmatization)
- 품사 정보와 사전을 기반으로 기본형 추출

예시)
beautiful → beautiful
studies → study

③ 차이점
- 어간 추출: 규칙 기반, 품사 무시
- 표제어 추출: 사전 및 품사 정보 기반


5. 불용어 처리 (Stopwords)

- 분석에 불필요한 토큰을 제거하는 작업
- 자주 사용되지만 분석에 중요한 의미를 갖지 않는 단어 제거
- 분석 목적에 따라 불필요한 품사를 제거하기도 함

예시)
the, a, an


6. 핵심 개념 정리

텍스트 전처리 → 분석에 적합한 형태로 변환
문장 토큰화 → 문장 단위로 분리
단어 토큰화 → 단어 또는 형태소 단위로 분리
품사 태깅 → 토큰의 품사 식별
개체명 인식 → 사람, 조직, 지역 등의 개체 식별
어간 추출 → 규칙을 적용하여 어간 추출
표제어 추출 → 품사와 사전을 활용하여 기본형 추출
불용어 처리 → 불필요한 단어 제거
