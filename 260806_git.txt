## pands
#### 데이터 분석 라이브러리
- 데이터 프레임(시리즈들이 모여서 만들어진 형태) == 엑셀과 비슷한 형태  
- 사용자가 정의한 자료형 == 시리즈(하나의 열로만 구성 = 1차원)  

#### 자료형
- 문자열 타입 => object
- datatime => 날짜와 시간 
- 나머지는 다 똑같음(int, float)

#### series
##### numpy의 1차원 array와 비슷

- 해당 조건이 일치하는 것만 데이터 변경 (np.where 대신 apply, map을 보통 씀)
- 해당 조건에 일치하는 것만 바꾸고 나머지는 NaN
- 행 추가

### loc, iloc

- 명시한 index로 접근
#### iloc
