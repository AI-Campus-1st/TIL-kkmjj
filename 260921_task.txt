Auto Encoder 논문

[Encoder-Decoder 구조]

- Autoencoder는 Encoder와 Decoder로 구성된 신경망 구조이다.
- Encoder는 입력 데이터를 압축하여 잠재 표현(Latent Representation)으로 변환한다.
- 이 과정에서 입력 데이터의 중요한 특징을 추출하고, 의미 있는 저차원 표현을 학습한다.
- Decoder는 Encoder가 생성한 잠재 표현을 이용하여 원래 입력 데이터와 최대한 유사하게 복원한다.
- 전체적인 데이터 흐름은 다음과 같다.

입력 데이터 → Encoder → Latent Representation → Decoder → 복원된 데이터

- 일반적으로 잠재 표현의 차원을 입력보다 작게 만드는 Bottleneck 구조를 사용한다.
- Bottleneck은 단순히 입력을 그대로 복사하는 것을 방지하고, 데이터의 핵심적인 특징을 압축하여 학습하도록 한다.
- 선형 Autoencoder는 PCA와 유사한 잠재 표현을 얻을 수 있으며, 비선형 신경망을 사용하는 Autoencoder는 더 복잡한 비선형 데이터 구조를 학습할 수 있다.


[Reconstruction]

- Autoencoder의 핵심 학습 목표는 입력 데이터를 다시 복원(Reconstruction)하는 것이다.
- 입력 데이터를 Encoder를 통해 잠재 표현으로 압축한 후, Decoder를 통해 원래 입력 데이터와 유사한 형태로 복원한다.
- 원본 입력 데이터와 복원된 데이터의 차이를 Reconstruction Loss(복원 손실)로 측정한다.
- 학습 과정에서는 이 Reconstruction Loss가 최소화되도록 Encoder와 Decoder를 학습한다.
- 논문에서는 일반적으로 L2-norm과 같은 방법을 이용하여 원본 데이터와 복원된 데이터 사이의 차이를 측정한다고 설명한다.
- 복원 성능이 좋다는 것은 압축된 잠재 표현에 원본 데이터를 복원하는 데 필요한 중요한 정보가 잘 포함되어 있다는 것을 의미한다.
- Denoising Autoencoder는 노이즈가 추가된 입력 데이터를 받아 원래의 깨끗한 데이터를 복원하도록 학습한다.


[Unsupervised Learning]

- Autoencoder는 대표적인 비지도 학습(Unsupervised Learning) 방법이다.
- 학습 과정에서 별도의 정답 Label이 필요하지 않으며, 입력 데이터 자체를 복원해야 할 대상으로 사용한다.
- 즉, 입력 데이터를 다시 원래의 데이터와 유사하게 복원하는 과정에서 데이터의 특징과 구조를 학습한다.
- Autoencoder의 주요 목적은 단순히 입력을 복사하는 것이 아니라 데이터의 의미 있는 잠재 표현을 학습하는 것이다.
- 학습된 잠재 표현은 차원 축소, 특징 추출, 군집화(Clustering), 이상 탐지(Anomaly Detection) 등 다양한 작업에 활용할 수 있다.
- 또한 비지도 학습으로 Encoder를 먼저 학습한 뒤, Encoder가 추출한 특징을 분류 모델에 활용할 수도 있다.

GAN 논문 리뷰

[Generator]

- Generator(생성자)는 실제 데이터와 유사한 새로운 데이터를 생성하는 역할을 한다.
- 무작위로 생성된 Noise를 입력으로 받아 실제 데이터와 같은 형태의 샘플을 생성한다.
- Generator의 목표는 생성된 데이터를 Discriminator가 실제 데이터라고 판단하도록 만드는 것이다.
- 학습이 진행될수록 실제 데이터의 분포를 학습하여 점점 더 실제와 유사한 데이터를 생성하게 된다.
- 논문에서는 Generator를 위조지폐를 만드는 위조범에 비유한다.
- 최종적으로 Generator가 생성하는 데이터의 분포가 실제 데이터의 분포와 같아지는 것을 목표로 한다.


[Discriminator]

- Discriminator(판별자)는 입력된 데이터가 실제 데이터인지 Generator가 생성한 가짜 데이터인지 구별하는 역할을 한다.
- 실제 데이터에는 높은 확률을, Generator가 만든 데이터에는 낮은 확률을 출력하도록 학습한다.
- 즉, 실제 데이터는 실제라고 판단하고 생성된 데이터는 가짜라고 정확하게 판단하는 것이 목표이다.
- 논문에서는 Discriminator를 위조지폐와 진짜 지폐를 구별하는 경찰에 비유한다.
- Generator의 성능이 향상될수록 가짜 데이터를 구별하기 어려워진다.
- 이상적인 상태에서는 Generator가 실제 데이터와 같은 분포를 생성하기 때문에 Discriminator가 실제와 가짜를 구별할 수 없게 된다.


[Adversarial Training]

- Adversarial Training(적대적 학습)은 Generator와 Discriminator가 서로 경쟁하면서 동시에 성능을 향상시키는 학습 방식이다.
- Discriminator는 실제 데이터와 생성된 데이터를 더 정확하게 구별하도록 학습한다.
- 반대로 Generator는 Discriminator를 속일 수 있도록 더 실제와 유사한 데이터를 생성하도록 학습한다.
- 실제 학습에서는 Discriminator와 Generator를 번갈아가며 업데이트한다.
- 이러한 과정은 두 모델이 서로 반대되는 목표를 가진 Minimax Game의 형태로 이루어진다.
- Generator는 Discriminator의 판단 결과를 통해 학습하며 점차 실제 데이터의 분포에 가까운 데이터를 생성하게 된다.
- 최종적으로 Generator가 실제 데이터와 같은 분포를 학습하면 Discriminator는 실제 데이터와 생성된 데이터를 구별할 수 없게 된다.
- 이때 Discriminator가 실제 데이터라고 판단할 확률은 50%가 된다.

YOLO 논문 리뷰

[End-to-End 학습]

- YOLO는 객체 탐지의 여러 단계를 하나의 신경망으로 통합한 End-to-End 방식의 모델이다.
- 기존 객체 탐지 방식은 후보 영역 생성, 특징 추출, 분류, Bounding Box 조정 등의 여러 단계를 각각 처리했다.
- YOLO는 전체 이미지를 한 번에 입력받아 Bounding Box와 클래스 확률을 동시에 예측한다.
- 하나의 신경망에서 전체 객체 탐지 과정이 이루어지기 때문에 탐지 성능을 기준으로 전체 모델을 함께 학습할 수 있다.
- 이러한 통합 구조는 기존의 복잡한 객체 탐지 파이프라인을 단순화하고 빠른 처리를 가능하게 한다.


[Bounding Box Regression]

- YOLO는 객체 탐지를 하나의 Regression(회귀) 문제로 정의한다.
- 입력 이미지를 여러 개의 Grid Cell로 나누고, 각 Grid Cell에서 Bounding Box와 Confidence Score를 예측한다.
- 각 Bounding Box는 객체의 중심 위치, 너비, 높이, Confidence 값으로 구성된다.
- 객체의 중심이 위치한 Grid Cell이 해당 객체를 탐지하는 역할을 담당한다.
- Confidence Score는 Bounding Box 안에 객체가 존재할 가능성과 예측한 Bounding Box의 정확도를 반영한다.
- YOLO는 Bounding Box의 위치와 클래스 확률을 하나의 신경망에서 동시에 예측한다.


[실시간 OD]

- OD(Object Detection)는 이미지에서 객체의 종류와 위치를 동시에 탐지하는 작업이다.
- YOLO는 하나의 이미지를 한 번의 신경망 연산으로 처리하기 때문에 매우 빠른 객체 탐지가 가능하다.
- 기본 YOLO 모델은 초당 45프레임(FPS)을 처리하여 실시간 객체 탐지가 가능하다.
- 더 작은 구조인 Fast YOLO는 초당 155프레임까지 처리할 수 있다.
- 기존 객체 탐지 방식처럼 여러 단계의 복잡한 처리 과정이 필요하지 않아 빠른 속도를 낼 수 있다.
- 따라서 웹캠이나 영상과 같이 연속적으로 입력되는 데이터에서도 실시간으로 객체를 탐지할 수 있다.
- 다만 빠른 속도를 얻는 대신 작은 객체나 객체의 정확한 위치를 찾는 부분에서는 일부 한계가 있다.
