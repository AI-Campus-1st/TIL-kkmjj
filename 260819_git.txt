검색 함수

Math - 처음부터
- 문자열의 시작이 패턴과 맞는지만 봄
Ex)
text = 'I like orange! I love orange!'
re.match('I like', text)
-> <re.Match object; span=(0, 6), match='I like'>
- 시작 부분만 검사하므로 중간에 있는 값은 못찾음

Search - 전체 하나
- 문자열 어디에 있든 처음 만난 것을 돌려줌
EX)
result = re.search("orange", text)
print(result)
->  <re.Match object; span=(7, 13), match='orange
* 존재 여부를 확인할 때 가장 많이 사용
* 없으면 None -> 바로 .group()을 부르면 오류가 남 =if로  사용
* 전체에서 가장 먼저 잡힌 것
* MatchObject.group() -> 매치된 텍스트를 가져올 수 있다.

Findall - 전부 리스트로
- 매치되는 모든 문자열을 리스트로 받음 
EX)
result = re.findall("orange", text)
print(result)
-> # ['orange', 'orange']
*  Find 전부 리스트로 반환
* 없는 목록 == 빈 리스트

Finditer - 위치까지 필요할 때
- Match 객체를 하나씩 꺼내 쓸 수 있음 
EX)
for m in re.finditer("orange", text):
	print(m.group(), m.start(), m.end()
-> orange 7 13 
* 값 뿐만 아니라 위치가 필요할 때 사용

Match 객체
- 검색에 성공하면 돌려받는 것
메서드	돌려주는 것	
group()	매치된 문자열	'orange'
start()	시작 위치	7
end()	끝 위치	13
span()	시작과 끝을 튜플로	(7,13)

# 표현식 : orange

I like orange! I love orange!

^ | $ -> 시작과 끝
- 문자열의 경계를 지정
# ^문자열의 시작
EX) ^I like
# $문자열의 끝
EX) orange!$
* ^ 없이 검증하면 “포함만 해도 통과”가 됨

. -> 모든 문자
# .
EX) 문자가 하나씩 추출 (공백도 하나로 인식)
# ….
EX) 네 글자씩 묶여 추출
- 줄바꿈은 제외
* re.DOTALL -> 줄바꿈까지 포함
* HTML 다룰 때 -> [^>] 좁혀쓰는 편이 안전

[] -> 범위 지정
- 대괄호 안의 문자 중 하나와 맞음
# [orn]
-> # o 또는r 또는n 한글자
# [0-9]
-> 숫자한글자
# [A-Za-z]
-> 영문한글자 (대/소문자 포함)
#  [ 가- 힣]
-> 한글 한글자

* 범위 -> -
* 대괄호 안에서는 대부분의 기호가 특별한 뜻이 없어짐

[^] -> 부정
- 대괄호 안의 것만 빼고 전부
# [^A-Za-z]
-> 영문이 아닌 것
# [^0-9]
-> 숫자가 아닌 것
# HTML 태그 정제 기본
<[^>]+>  
-> 태그 전체

* ^ 가 대괄호 안에 있으면 부정 / 밖에 있으면 시작
* <[^>]+> 태그를 지울 때 쓰는 가장 기본적인 패턴
* [^X] 과하게 삼키는 사고 막을 수 있음

() -> 그룹과 | 선택
- 묶고, 잇기
# (orange)
-> 묶음
# (oragnelike)
-> orange 또는 like

# 그룹은 findall의 결과를 바꿈
re.findall("(0[0 - 9]{1,2}) - ([0 - 9]{3,4})", " 02- 123- 4567 031 - 9876- 5432")

-> 0[0~9까지중에]{1개 또는 2개} - [0~9까기중에]{3개 또는 4개}

* 그룹은 묶기, 꺼내기 두 역할을 함
* Findall에 그룹이 있으면 그룹만 돌려줌 
* 묶기만 하려면 (?:)

수량자
기호	의미	예시	걸리는 것

이스케이프

- 기호 자체를 찾고 싶을 때는 앞에 역슬래시
# \$
-> 달러 기호 자체를 찾음
# \.
-> 마침표 자체를 찾음
이스케이프가 필요한 기호 : \ ^ $ * + ? . [ ] ( ) 
*  파이썬에서 패턴  r”….”  -> 역슬래시 두번 적지 않아도 가능
* 도메인이 파일명처럼 마침표가 들어간 값에서 중요
* Re.escape()로 문자열 전체를 안전하게 만들 수 있음

?= -> 전방 탐색
- 뒤에 무엇이 오는지 조건으로 걸지만, 결과에는 넣지 않음
# oran(?=ge!)
I like orange! I love orange
-> 결과는oran  | — ge! 는조건일 뿐 가져오지X
* 뒤에 원이 붙은 숫지만 같은 조건에 유용

?<= -> 후방 탐색
- 앞에 무엇이 왔는지 조건으로 검
# (?<=ora)nge!
I like orange! I love orang
-> nge! | — ora  조건

* 앞 문맥이 단서일 때 사용
* 길이가 고정돼야 하는 제약이 있음

?! -> 부정형
- 그것만 아니면 됨
# span 안에 br 태그가 없는 것만
<span>((?!<br>).)*</span>

# 특정 확장자를 제외한 링크
href="(?!.* \ .pdf).*?"
* 예외를 빼고 수집할 때 사용

Sub -> 치환
- 찾은 것을 다른 것으로 바꿈. 정제의 주력
EX)
import re
text = """
수강해야하는 과목
(machine learning, deep learning)
수강한과목
[python, django, web design]
"""
re.sub(r"\ [.+ \ ]", "", text)
-> 수강해야하는 과목
	(machine learning, deep learning)
	수강한과목
* 빈 문자열로 바꾸면 -> 삭제
* 태크, 엔티티, 말머리를 걷어내는 데 사용
* 치환할 자리에 함수를 넣어 값을 다르게 할 수 있음 

데이터 수집 흐름상에서 Regex 역할
1. fetch() : 요청을 보내고 응답을 돌려줌
2. parse() : HTML에서 필요한 조각을 꺼냄
3. clean() : 꺼낸 값을 다듬어줌

재사용할 정제 함수
- 자주 사용할만한 함수를 한 번 만들어주고 재사용
EX)
import re, html
def clean_text(s):
	s = re.sub(r"<[^>]+>", "", s) 		# 남은태그
	s = html.unescape(s) 				# &nbsp; 같은엔티티
	s = re.sub(r" \ s+", " ", s) 			# 연속공백
	s = re.sub(r" \ [[^ \ ]]* \ ]", "", s) 		# [ 단독 ] 말머리
	return s.strip()
* 크롤러 파일이 아니라 별도 모듈로 분리
